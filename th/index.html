คำถามที่พบบ่อย

WanaGo ใช้ฟรีไหม?
ใช่ ทุกฟีเจอร์ใช้ได้ฟรี — ไม่ต้องสมัครบัญชี ไม่มีช่วงทดลองใช้ และไม่มีแพ็กเกจแบบเสียเงิน WanaGo จะได้รับค่าคอมมิชชันเล็กน้อยเมื่อมีผู้จองเที่ยวบินหรือโรงแรมผ่านวิดเจ็ตของพาร์ทเนอร์ โดยนักเดินทางไม่ต้องจ่ายเพิ่มแม้แต่บาทเดียว
WanaGo เก็บข้อมูลของฉันหรือไม่?
ไม่ บุ๊กมาร์ก การตั้งค่า และรายการสิ่งที่ต้องทำของคุณถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น และไม่ถูกส่งออกไปไหน WanaGo ขอสิทธิ์เพียง storage เท่านั้น และไม่มีสคริปต์วิเคราะห์หรือติดตามใดๆ เพื่อแนะนำจุดหมายใกล้ตัวคุณเมื่อติดตั้งครั้งแรก WanaGo จะอ่านเขตเวลาและภาษาของเบราว์เซอร์บนอุปกรณ์ของคุณเท่านั้น — ไม่มีการส่งข้อมูลออกไปที่ใดเลย
WanaGo รองรับภาษาอะไรบ้าง?
WanaGo มีให้ใช้งานใน 52 ภาษา ระบบจะเปลี่ยนตามภาษาของเบราว์เซอร์โดยอัตโนมัติ และสลับได้ทุกเมื่อในการตั้งค่า นอกจากนี้ยังค้นหาจุดหมายได้ด้วยการพิมพ์ชื่อสถานที่เป็นภาษาอังกฤษหรืออีก 22 ภาษา เช่น ไทย ญี่ปุ่น เกาหลี จีน อาหรับ และฮินดี
ภาพพื้นหลังมาจากไหน?
ภาพทั้งหมดกว่า 1,000 ภาพมาจาก Unsplash และ Pixabay ภายใต้สัญญาอนุญาตที่ให้ใช้งานได้ฟรี ภาพพื้นหลังทุกภาพให้เครดิตช่างภาพไว้ที่มุมของแท็บใหม่ พร้อมลิงก์ไปยังภาพต้นฉบับ
WanaGo ใช้กับ Edge และ Firefox ได้ไหม?
ได้ WanaGo เผยแพร่บน Chrome Web Store, Microsoft Edge Add-ons และ Firefox Add-ons โดยมีฟีเจอร์เหมือนกันทั้งสามแพลตฟอร์ม
เลือกประเทศและหมวดหมู่ที่จะแสดงได้ไหม?
ได้ แถบการตั้งค่าด้านข้างให้คุณกรองตามหมวดหมู่ (เมือง วัฒนธรรม ธรรมชาติ) ตามทวีป หรือเลือกเฉพาะประเทศและภูมิภาคที่ต้องการ และยังตั้งให้วนแสดงเฉพาะจุดหมายที่บุ๊กมาร์กไว้ได้ด้วย
ลิงก์จองมีค่าใช้จ่ายเพิ่มหรือไม่?
ไม่มี ลิงก์จะเปิด Expedia หรือ Trip.com ด้วยราคาปกติที่แสดงต่อสาธารณะ หากคุณจอง เราอาจได้รับค่าคอมมิชชันเล็กน้อยจากเว็บไซต์ท่องเที่ยว ซึ่งไม่ทำให้ราคาที่คุณจ่ายเปลี่ยนไปเลย
ถอนการติดตั้ง WanaGo อย่างไร?
คลิกขวาที่ไอคอน WanaGo บนแถบเครื่องมือของเบราว์เซอร์แล้วเลือก นำออก หรือเปิดหน้าส่วนขยายของเบราว์เซอร์ ค้นหา WanaGo แล้วเลือก นำออก แท็บใหม่จะกลับเป็นค่าเริ่มต้นทันที

常見問題

WanaGo 是免費的嗎？
是的。所有功能都免費 — 不用註冊帳號、沒有試用期，也沒有付費方案。當有人透過合作夥伴小工具預訂機票或飯店時，WanaGo 會獲得少許佣金，旅客不需支付任何額外費用。
WanaGo 會收集我的資料嗎？
不會。你的書籤、設定和待辦清單都儲存在你自己的裝置上，絕不外傳。WanaGo 只要求 storage 權限，不含任何分析或追蹤程式碼。為了在首次安裝時推薦附近的目的地，WanaGo 只會在你的裝置上讀取瀏覽器的時區和語言 — 不會傳送到任何地方。
WanaGo 支援哪些語言？
WanaGo 提供 52 種語言，會自動跟隨瀏覽器語言，也可隨時在設定中切換。搜尋目的地時，除了英文，也能用泰文、日文、韓文、中文、阿拉伯文、印地文等另外 22 種語言輸入地名。
桌布照片從哪裡來？
全部 1,000 多張照片皆來自 Unsplash 與 Pixabay，並採用允許免費使用的授權。每張桌布都會在新分頁角落標註攝影師，並附上原圖連結。
WanaGo 可以在 Edge 和 Firefox 上使用嗎？
可以。WanaGo 已在 Chrome Web Store、Microsoft Edge Add-ons 和 Firefox Add-ons 上架，三個平台的功能完全相同。
可以選擇要看哪些國家和類別嗎？
可以。在設定側邊欄中，可依類別（城市、文化、自然）、洲別或特定國家和地區篩選，也可以只輪播你收藏的目的地。
透過預訂連結需要額外付費嗎？
不需要。連結會以一般公開價格開啟 Expedia 或 Trip.com。若你完成預訂，我們可能會從旅遊網站獲得少許佣金，但絕不影響你支付的金額。
如何解除安裝 WanaGo？
在瀏覽器工具列的 WanaGo 圖示上按右鍵，選擇移除；或開啟瀏覽器的擴充功能頁面，找到 WanaGo 後選擇移除。新分頁會立即恢復為預設畫面。

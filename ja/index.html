WanaGo New Tab

次の旅先に迷ったら、新しいタブを開こう。

新しいタブを開くたびに、50の国と地域の絶景やランドマーク1,000か所以上から、息をのむようなフルHD旅行壁紙が登場。航空券・ホテルもその場で検索できて — 52言語に対応しました。

✨ すべての機能が100%無料

機能

🌍

50の国と地域を旅しよう

活気あふれる都市から大自然の絶景まで、50の国と地域から1,000枚以上の美しい旅行壁紙をランダムにお届け。カテゴリー・大陸・国で簡単に絞り込めます。

🗣️

あなたの言語で

WanaGo は52言語に対応。ブラウザの言語に自動で合わせ、設定からいつでも切り替えられます。地名や国名もあなたの言語で表示されます。

🧳

旅の計画もスムーズに

各旅行先周辺の航空券やホテルを Expedia と Trip.com でその場で検索し、お得なプランを比較。デフォルトの宿泊人数や予約時期もダッシュボードで自由に設定できます。

🔍

ビジュアル検索 & AI

1,000以上の旅行先を写真プレビュー付きですぐに検索。英語のほか、タイ語、日本語、アラビア語、ヒンディー語など22の言語でも入力でき、Google 検索（文字・音声）や Gemini AI にもワンクリックでアクセスできます。

⚡

高速 & オフライン対応

次の壁紙を前もって準備しておくので、新しいタブもシャッフルも一瞬で表示。最近の壁紙はオフラインでも表示でき、メインサーバーが遅いときはバックアップの画像サーバーに自動で切り替わります。

✅

シンプルなToDoリスト

直感的に使えるタスク管理とチェックリストを内蔵。余計なものに気を取られず、すっきりした環境で毎日の作業に集中できます。

⭐

インタラクティブなブックマーク

お気に入りの旅行先を保存して、自分だけの「いつか行きたいリスト」を作成。ドラッグ&ドロップでいつでも並べ替えられます。

🌐

カスタマイズできる世界時計

12時間・24時間表示を切り替え（非表示も可）。現在地の時刻や、表示中の旅行先の時刻を手軽にチェックできます。

🗺️

すぐに探索

地図のピンをクリックすれば、場所の詳細や有名なランドマーク、ルートを Google Maps ですぐに確認できます。

⌨️

スペースキーのショートカット

いつでも「Space」キーを押すだけで、新しい絶景の旅行壁紙に瞬時に切り替わります。

⚙️

自分好みにカスタマイズ

Glassmorphism デザインの設定で、ダッシュボードを自分好みに。旅行先フィルター、予約のデフォルト設定、ミニマルなウィジェットの表示切り替え、お気に入りだけのループ表示も可能です。

📸

撮影者クレジット付きの写真

Unsplash と Pixabay から厳選した写真を使用。すべての壁紙に撮影者のクレジットと元の写真へのリンクを表示しています。

よくある質問

WanaGo は無料ですか？
はい。すべての機能が無料です — アカウント登録も、試用期間も、有料プランもありません。提携ウィジェットから航空券やホテルが予約されると WanaGo に少額の手数料が入りますが、旅行者の負担が増えることはありません。
WanaGo は私のデータを収集しますか？
いいえ。ブックマーク、設定、ToDoリストはお使いのデバイス内にローカル保存され、外部に送信されることはありません。WanaGo が求める権限は storage のみで、アクセス解析やトラッキングのスクリプトも一切含みません。初回インストール時に近くの旅行先を提案するため、ブラウザのタイムゾーンと言語をデバイス上でのみ読み取ります — どこにも送信されません。
WanaGo はどの言語に対応していますか？
WanaGo は52言語に対応しています。ブラウザの言語に自動で合わせ、設定からいつでも切り替えられます。旅行先の検索では、英語のほか、タイ語、日本語、韓国語、中国語、アラビア語、ヒンディー語など22の言語でも地名を入力できます。
壁紙の写真はどこから来ていますか？
1,000枚以上の写真はすべて、無料で利用できるライセンスのもと Unsplash と Pixabay から提供されています。すべての壁紙で、新しいタブの隅に撮影者のクレジットと元の写真へのリンクを表示しています。
WanaGo は Edge や Firefox でも使えますか？
はい。WanaGo は Chrome Web Store、Microsoft Edge Add-ons、Firefox Add-ons で公開されており、どれでも同じ機能をお使いいただけます。
表示する国やカテゴリーは選べますか？
はい。設定サイドバーで、カテゴリー（都市・文化・自然）、大陸、または特定の国と地域で絞り込めます。ブックマークした旅行先だけを順番に表示することもできます。
予約リンクを使うと追加料金はかかりますか？
いいえ。リンク先の Expedia や Trip.com では、通常の一般価格がそのまま表示されます。予約された場合、旅行サイトから少額の手数料を受け取ることがありますが、お支払い額が変わることはありません。
WanaGo をアンインストールするには？
ブラウザのツールバーにある WanaGo のアイコンを右クリックして 削除 を選ぶか、ブラウザの拡張機能ページで WanaGo を探して 削除 を選択してください。新しいタブはすぐに元の状態に戻ります。
